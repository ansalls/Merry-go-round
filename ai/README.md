# AI

Resources, ideas, and perspectives on building with AI, emerging architectures, and what looks likely to matter long-term. The emphasis is on practical insight: what works, what doesn't, and where the field seems to be heading.

## Resources

### Context Windows are Stupid (and possible alternatives)
📺 [YouTube — BmGC58Opifc](https://youtu.be/BmGC58Opifc?si=T3a-IhmxVfhLNddk)

A critical look at the context-window paradigm that dominates current large language model design, with exploration of alternative approaches to memory and context management that could prove more scalable and useful in the long run.

### I built a persistent AI assistant with Claude Code + Obsidian + QMD, and it's starting to feel like a real long-term "second brain"
